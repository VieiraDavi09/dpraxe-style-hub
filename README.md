# D'Praxe Digital Style

Crie um site profissional, moderno e responsivo para a D'PRAXE BARBEARIA, uma barbearia localizada em Av. Giovanni Gronchi, 5930 – Vila Andrade, São Paulo – SP, Shopping Morumbi Town, Piso Térreo.

Use a imagem de referência enviada nesta conversa para entender a identidade visual da barbearia, principalmente o logotipo, tipografia e estilo da marca.

🎨 IDENTIDADE VISUAL

O site deve ter uma estética de barbearia premium, masculina, elegante e moderna.

Fundo predominantemente preto / preto carvão
Detalhes em branco, bege/off-white e dourado envelhecido
Visual sofisticado, mas sem parecer exageradamente luxuoso
Usar bastante contraste
Tipografia forte e masculina nos títulos
Tipografia moderna e limpa nos textos
Animações suaves ao passar o mouse e durante o scroll
Bordas discretas e elementos com aparência premium
O logo da D'PRAXE BARBEARIA deve aparecer em destaque no header
Não criar uma identidade visual completamente diferente da imagem de referência
Priorizar um design que pareça de uma barbearia real e estabelecida
